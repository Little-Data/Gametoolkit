\[教学\]PS Rom 汉化中tim格式图片的导入导出与修改方法   作者：海宁


## 前言

最近做游戏汉化的人越来越多了。把我们多数人看不懂或不全懂的的鸟语（英语），特别是日语翻译成我们的母语，本身就是功德一件。向你们汉化人致敬！汉化多数停留在FC,MD,SFC等16位机上，技术已经很成熟。但是PLay Stantion等32位机汉化的游戏就比较少，主要原因是缺少汉化工具，资料和交流汉化经验。我把我做ps汉化时所得到的一点经验和方法全部奉献出来，希望对有志汉化ps rom的朋友有所帮助。


## 一、准备工作

好，进入正题。首先，我们要具备以下这些才能开始：

1 Timcolcn ps Tim格式图片浏览与导出工具软件

2 photo Shop 6.0 这个不用多说了吧，呵呵^_^

3 Timplugs photo Shop 6.0插件，使其能编辑修改Tim格式图片

4 一款支持自定义文件大小的文件分割器，我用的是：金锋文件分割与合并1.0标准版

5 一款你爱用的十六进制文件编辑器，我用的是：UltraEdit-32

6 对游戏汉化的热情和自信，极大的耐心加要有业余时间


## 二、文件的导出

用Timcolcn打开ps cd 文件。带Str，Xa，T m d（Dark01：874联盟论坛的脏话过滤器）后缀名是动画.音频.3D建模的文件，我们可以不用理它们。找到要导出修改的图片，点选图片然后取个名字保存即可，简单易行。如图,我们要导出机战阿咯发的字库(用字库做例我只想说明字库也常是以Tim格式图片存放的),步骤如下：

选择要打开的文件

保存文件为TIM格式


## 三、文件的编辑

用Photo Shop 载入刚才你导出的图片。因为编辑的图片不是RGB格式，我们得把它转成需要的RGB色才能设制图层，编辑和修改.值得注意的是在转色之前一定要把Tim图片的颜色表储存起来，编辑前后的大小尽量保持一致。如要大于原图除非你确信在下一幅连贯的图片之间有剩余的储存空间或扩容(最好不要这么做,因为这样就改变了文件的大小,以后做成镜像时可能会遇到意想不到的问题)。
完成后再载入颜色表然后保存。否则你导入测试的时候看到的将是花屏.编辑的方法和一般的图片的修改没什么两样,我想这不用我多说了吧,呵呵.颜色表转换操作步骤如下:

编辑前

1、图像→模式→颜色表→存储

2、图像→模式→RGB颜色

编辑完成后

3、图像→模式→颜色表→载入


## 四、文件的导入

文件的导入是一件繁杂的工作,需要很大的耐心跟细心。当你沉迷下去会感到：痛苦并快乐着。呵呵。
Ps Tim文件一般包含在BIN等大的文件中。编辑修改的图片要导回去替换掉原文件才能达到我们的目地。Tim文件的导入现堦段还没发现有方便直观的工具。经过研究思考，我想到了两种方法来达成。

A：适合包含在比较小的文件（一兆---几十兆左右）中的导入。在开始之前，我们来了解一下Tim文件的数据结构，看图： 

```
文件头:

[1-4] - 10 00 00 00 : TIM 图片格式文件头标记
[5-8] - 08 00 00 00 或 00 00 00 00 : 图像精灵为4BPP(BPP为图片一小块的像素)
- 09 00 00 00 或 01 00 00 00 : 图像精灵为8BPP
- 02 00 00 00 : 图像精灵为16BPP
- 03 00 00 00 : 图像精灵为24BPP
[9-12] - 调色板面积 + 12 
[13-14] - 调色板 X
[15-16] - 调色板 Y
[17-18] - 调色板颜色数
[19-20] - 调色板大小

数据区:
[21-??] -略......
```

我们只要记住TIM文件是以10 00 00 00 标记开头的就可以了。

第一步 把包含TIM图片的文件拷到硬盘,用十六进制文件编辑器打开它。

第二步 再打开一个十六进制文件编辑器窗口，载入Tim原始图片文件（不是修改过的）,查看记录下一些你认为比较特殊的连贯代码值或文本栏的ASCII字符。

第三步 在打开包含TIM图片文件的十六进制文件编辑器中用查找功能查找你刚才记录下的东东,一般你会找到一到几个地址。比较一下原代码,找出正确的地址,找到文件头，记录下10 00 00 00中10 的地址备用。

第四步 再用一个编辑窗口打开修改过的Tim图片文件,选择全部复制，然后回到包含TIM图片文件的十六进制文件编辑窗口中。找到刚记下的地址，在这里选择粘贴，文件起名保存即可。 

最后一步就是用Timcolcn 打开看看起名保存的文件里的TIM图片是不是已替换成功。失败的话，大多是找文件头地址时出了问题。如是多出了一幅相同的图的话,一般是第四步出了问题.因为有些十六进制文件编辑器在在第四步选粘贴时默认编辑方式是插入。另外一些默认编辑方式是覆盖的编辑器就没有这种问题。解决办法是设为覆盖方式或把要替换的数据删除再插入新数据。

B: 那些小则百把兆大则几百兆的文件怎么办呢？如果内存小的电脑一样用十六进制文件编辑器打开的话简直是一场恶梦。嗯，既然太大，我们就“化整为零”吧，分割了它！这里我们用到了文件分割器这个好东东。用文件分割器把原始文件分割成若干文件，分割文件的大小以你的编辑器现能打开文件的大小为限。(分割器用法不再叙述,中文多多，一目了然^_^) 用Timcolcn 打开你刚分割成的文件，逐个寻找到你想要修改图片所在的那一个文件。照A的方法用你聪明的大脑+艺术细胞编辑它们吧，呵呵。 最后与其它文件合并,搞掂。

小窍门：在比较大的文件里你可能找到一大堆图片，在编辑器里寻找想要图片的地址真是一件伤神的事。不管文件的大小，只要包含的图片文件太多时都推荐使用方法B，你可以省去很多时间与麻烦，不用为找到很多相同的地址而烦恼或去面对象0xXXXXXXXXXh等 N 位数以上的地址了。事半功倍哟。
